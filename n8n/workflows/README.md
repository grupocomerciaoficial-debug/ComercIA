# Exportaciones de workflows

Los flujos se organizan por versión:

- `V1/`: primera versión exportada de WF-01 a WF-12 y SUB-01.
- `V2/`: segunda versión exportada de WF-01 a WF-12 y SUB-01.

Importa los archivos de una misma versión en n8n y recrea las credenciales directamente en la instancia. Antes de actualizar un export, comprueba que no incluya credenciales, tokens, URLs privadas ni datos reales de clientes.
