# Aseguramiento de calidad

Esta carpeta contiene los informes de pruebas V1 y V2 en `resultados/`. Los informes describen las validaciones ejecutadas para las versiones entregadas del MVP.

Para agregar resultados nuevos, registra la versión, fecha, commit evaluado, ambiente, casos ejecutados, aprobados, fallidos y bloqueos. Usa datos ficticios o anonimizados en cualquier evidencia.
